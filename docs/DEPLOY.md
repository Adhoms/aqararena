# نشر الموقع أونلاين (Deploy) — Vercel + Neon

الموقع بيتنشر على **Vercel** (استضافة مجانية لمواقع Next.js)، وقاعدة البيانات على **Neon** (PostgreSQL مجاني). الاتنين بيدخلوا بحساب GitHub، ومش محتاجين كارت فيزا في الخطة المجانية.

> كلمات السر وعناوين قاعدة البيانات **ماتتكتبش في الشات ولا في GitHub**. بتتحط في ملف `.env` على جهازك (الملف ده مش بيترفع) وفي إعدادات Vercel بس.

---

## 0) جهّز الكود على `main`

Vercel بينشر فرع `main` كموقع أساسي. ادمج الـ pull requests بالترتيب:

1. PR #2 — قاعدة البيانات
2. PR #3 — التصميم الذكي (حوّل الـ base بتاعه لـ `main` بعد دمج #2)
3. PR النشر ده

## 1) أنشئ قاعدة البيانات على Neon

1. ادخل على https://neon.tech واعمل حساب بـ GitHub.
2. **Create project**:
   - الاسم: `aqararena`
   - المنطقة (Region): **AWS Europe Central 1 (Frankfurt)** — الأقرب لمصر.
3. من زر **Connect** في الصفحة الرئيسية للمشروع خد نسختين من عنوان الاتصال:
   - **Pooled connection** (فيه كلمة `-pooler`) → ده `DATABASE_URL`
   - شيل علامة "Connection pooling" وخد العنوان التاني → ده `DIRECT_URL`

## 2) جهّز الجداول والبيانات من جهازك

في ملف `.env` على جهازك (مش `.env.example`):

1. حط `#` قبل سطور قاعدة البيانات المحلية الحالية (`DATABASE_URL`, `SHADOW_DATABASE_URL`, `DATABASE_POOL_MAX`).
2. أضف السطرين دول بالعناوين اللي نسختها من Neon:

```
DATABASE_URL="...العنوان الـ pooled..."
DIRECT_URL="...العنوان الـ direct..."
```

3. شغّل في الـ terminal:

```bash
npx prisma migrate deploy
```

ده بيعمل كل الجداول في Neon.

4. (اختياري) عشان الموقع مايبقاش فاضي لحد ما تضيف المشروعات الحقيقية، حمّل البيانات التجريبية — في PowerShell:

```powershell
$env:ALLOW_DEMO_SEED=1; npm run db:seed
```

بعد كده ترجّع `.env` لقاعدة البيانات المحلية لو عايز تشتغل على جهازك.

## 3) انشر على Vercel

1. ادخل على https://vercel.com واعمل حساب بـ GitHub.
2. **Add New → Project** → اختار الـ repo **Adhoms/aqararena** → Import.
3. Framework: **Next.js** (بيتعرف لوحده). سيب Build Command زي ما هو — المشروع فيه `vercel-build` اللي بيعمل:
   `prisma generate` ← `prisma migrate deploy` ← `next build`
4. افتح **Environment Variables** وأضف:

| الاسم | القيمة |
| --- | --- |
| `DATABASE_URL` | عنوان Neon الـ **pooled** |
| `DIRECT_URL` | عنوان Neon الـ **direct** |
| `ADMIN_PASSWORD` | كلمة مرور لوحة التحكم `/admin` (طويلة وصعبة، 16 حرف على الأقل) |

   ماتضيفش `DATABASE_POOL_MAX` ولا `SHADOW_DATABASE_URL` (دول للجهاز المحلي بس).
5. **Deploy**. بعد دقيقتين تقريبًا هتاخد رابط زي `aqararena.vercel.app`.
6. (مستحسن) **Settings → Functions → Function Region** → **Frankfurt (fra1)** عشان السيرفر يبقى جنب قاعدة البيانات.

## 4) بعد النشر

- كل push على `main` بينشر نسخة جديدة لوحده.
- كل pull request بياخد رابط معاينة (Preview) خاص بيه.
- الأسعار والبيانات بتتحدّث في الموقع كل ساعة، وفورًا عند الحفظ من لوحة التحكم.

## 4-ب) الدومين: aqararena.com

الدومين **aqararena.com** متسجّل من Vercel نفسه (3 نوفمبر 2026)، وبيتجدد تلقائيًا كل سنة (حوالي 12 دولار، التجديد الجاي 3 نوفمبر 2027). الـ DNS على Vercel، فمافيش إعدادات DNS محتاجة تتعمل.

- **Project → Settings → Domains**:
  - `aqararena.com` ← Production
  - `www.aqararena.com` ← تحويل دائم (308) على `aqararena.com`
  - `aqararena.vercel.app` ← لسه شغال كعنوان احتياطي
- **Environment Variables**: `NEXT_PUBLIC_SITE_URL = https://aqararena.com` (Production). ده اللي بيخلّي الـ sitemap و robots.txt والـ canonical وروابط المشاركة تستخدم الدومين. لو غيّرت الدومين، غيّر المتغير ده واعمل **Redeploy**.
- أي تغيير في المتغيرات مش بيبان غير بعد **Redeploy**، و Vercel ممكن يطلب كود تأكيد على الإيميل.

**خطوة جاية مستحسنة:** سجّل الموقع في [Google Search Console](https://search.google.com/search-console) (نوع Domain: `aqararena.com`)، وابعتله `https://aqararena.com/sitemap.xml`.

## 5) إدخال البيانات الحقيقية من لوحة التحكم

1. افتح `https://<الموقع>/admin` وادخل بكلمة المرور (`ADMIN_PASSWORD`).
2. **+ مطور**: الاسم بالعربي والإنجليزي، والأرقام الرسمية (الخط الساخن، المبيعات، واتساب، الموقع، المقر). علّم «أرقام موثّقة» بعد التأكد منها.
3. **+ مشروع**: البيانات الأساسية وموعد التسليم، ثم احفظ.
4. في صفحة المشروع أضف **نماذج الوحدات** (لازم نموذج واحد على الأقل بسعر)، و**أنظمة السداد**، ومناطق الماستر بلان، والصور، ورابط البروشور (نوع «بروشور PDF»).
5. فعّل **منشور على الموقع** واحفظ. المشروع يظهر فورًا في المشروعات والخريطة وصفحته، وفي «إطلاقات جديدة» لو حالته «إطلاق جديد».

لإخفاء مشروع مؤقتًا ألغِ «منشور» بدل الحذف. تغيير `ADMIN_PASSWORD` بيخرج أي جلسة مفتوحة.

### الصور والملفات (Vercel Blob)

جنب كل خانة رابط (الشعار، الماستر بلان، الصور) فيه زرار **رفع من الجهاز**، وفي قسم «الصور والملفات» في صفحة المشروع فيه صندوق **رفع عدة ملفات مرة واحدة**: تختار النوع والتبويب وتحدد الصور كلها مرة واحدة. الصور بتتصغّر وتتحول لـ WebP في المتصفح قبل الرفع، فالموقع يفضل سريع.

الملفات بتتخزن في **Vercel Blob** (Storage ← Blob store اسمه `aqararena-media` ومربوط بالمشروع). الربط ده بيضيف `BLOB_READ_WRITE_TOKEN` في Environment Variables لوحده. من غيره زرار الرفع بيقول إن الرفع مش مفعّل، ولسه تقدر تلصق روابط. لما تمسح صورة من لوحة التحكم، الملف بيتمسح من التخزين كمان لو مافيش حاجة تانية بتستخدمه.

### استيراد من Excel

**لوحة التحكم ← استيراد Excel**:

1. **تنزيل ملف فاضي**: ملف فيه شيتات المطورين والمشروعات والنماذج وأنظمة السداد، بقوايم تختار منها، وأول شيت فيه شرح كل عمود. أو **تنزيل البيانات الحالية** عشان تعدّل كتير مرة واحدة.
2. املاه وارفعه، واضغط **افحص الملف**. لو فيه أخطاء هتظهر بالشيت ورقم الصف والعمود، ومش هيتحفظ أي حاجة.
3. لو الملف سليم اضغط **استورد البيانات**. المطور أو المشروع اللي موجود بنفس الاسم أو الرابط المختصر بيتحدّث بدل ما يتكرر.

## 6) بوابة المطورين

كل مطور ليه حساب (اسم مستخدم وكلمة مرور) يعدّل منه بيانات شركته ومشروعاته، وأي تعديل بيستنى موافقتك قبل ما يظهر على الموقع.

**الحسابات** (لوحة التحكم ← الحسابات):
- **طلبات جديدة**: المطور بيطلب حساب من صفحة **للمطورين** (`/ar/dev`). بتختار هو تبع أنهي مطور على الموقع، أو تعمل مطور جديد من بيانات الطلب، وتضغط **تفعيل الحساب**.
- **عمل حساب لمطور**: تختار المطور وتكتب اسم مستخدم، فتظهرلك كلمة مرور مؤقتة **مرة واحدة**. ابعتها للمطور، وهو هيختار كلمة مرور جديدة أول ما يدخل.
- **كلمة مرور جديدة**: لو المطور نسي كلمة المرور. **إيقاف**: بيقفل الحساب ويخرّجه فورًا.

**المراجعة** (لوحة التحكم ← مراجعة المطورين): الرئيسية بتقولك لو فيه طلبات مستنية. في كل طلب بتشوف الحالي على الموقع جنب المقترح، والتغييرات متعلّم عليها، والصور الجديدة والمتشالة. بعدها:
- **موافقة ونشر التغييرات**: التعديل بيتنشر على الموقع على طول. المشروع الجديد بيتنشر لو "انشر المشروع" متعلّم عليه.
- **رجّعه للمطور**: تكتب له إيه اللي محتاج يتعدّل، فيشوف ملاحظتك ويعدّل ويبعت تاني.

المطور مايقدرش يغيّر: الرابط المختصر، "مميز"، "أرقام موثّقة"، ولا مناطق الماستر بلان. دول بيفضلوا من لوحة التحكم بس.

## لو حصلت مشكلة

| المشكلة | الحل |
| --- | --- |
| البناء فشل عند `prisma migrate deploy` | اتأكد إن `DIRECT_URL` هو العنوان **من غير** `-pooler`. |
| الموقع بيفتح بس مافيش مشروعات | قاعدة البيانات فاضية: نفّذ خطوة 2-4 أو أضف مشروعات حقيقية. |
| `DATABASE_URL is not set` | المتغيرات مش متضافة في Vercel، أو اتضافت بعد آخر Deploy — اعمل **Redeploy**. |
