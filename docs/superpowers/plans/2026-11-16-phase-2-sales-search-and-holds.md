# Phase 2: AqarArena Sales inventory search and temporary holds — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give a developer's salespeople an inventory search at `/sales`, a unit page with the payment calculator, and temporary holds (one per unit, guaranteed by the database) with a "my holds" list; let the developer set how long holds last.

**Architecture:** Same Next.js app and database (spec: `docs/superpowers/specs/2026-11-15-aqararena-three-products-design.md`, sections 2 to 6, 10.2 and 11). One additive migration adds `Developer.holdHours`, `Project.holdHours` and a `UnitHold` table, plus a hand-written partial unique index that allows one `ACTIVE` hold per unit. The rules (who may convert or cancel, when a hold counts, how long it lasts, budget math) are pure functions with unit tests; one server-only service (`src/lib/sales/hold-service.ts`) runs every hold write in a transaction. Portal and admin status changes release holds inside the same transaction that changes the unit. Sales pages are server components; the search keeps its filters in the URL.

**Tech Stack:** Next.js 16 (App Router, Cache Components, `next/form`), React 19, TypeScript, Tailwind CSS 4, Prisma 7.10 with `@prisma/adapter-pg` on PostgreSQL, Node's built-in test runner via `tsx`.

**Base branch:** `claude/aqararena-sales-search-holds`, stacked on `claude/aqararena-sales` (PR #20, open). Read `AGENTS.md`: this Next.js has breaking changes. The APIs this plan uses are documented in `node_modules/next/dist/docs/01-app/03-api-reference/`: `02-components/form.md` (`next/form`), `04-functions/not-found.md`, `04-functions/revalidatePath.md`, `03-file-conventions/not-found.md` (a `not-found.tsx` per root layout). `PageProps<"/route">` and `LayoutProps` are generated by `npx next typegen`; `params` and `searchParams` are promises.

**Local testing:** never use the main checkout's `.env` (it is the live database). From Task 5 on you need a throwaway database: `npx prisma dev --detach --name aqararena-p2-test` (it prints the port; the shadow database is that port + 1), a worktree `.env` built from `.env.example` with those two ports, then `npx prisma migrate deploy` and `npm run db:seed`. Keep it running until the end; the final task leaves cleanup to the controller.

Salespeople mostly use phones: check 360 px wide.

**What the code allows (checked while writing this plan):**
- **Master plan:** `MasterPlanZone` has no link to `Unit` or `Typology` (only `unitSubTypes`, a list of sub-types). A unit can't be placed on a zone, so the unit page shows the master plan image without marking. Marking needs a new `Unit.zoneId` (or typology-to-zone) link later.
- **Floor plans:** `Media.typologyId` exists, but no admin or portal screen sets it: floor plans are uploaded per project. The unit page shows the type's own floor plans when there are any, otherwise the project's floor plans and layout sketches, labelled as the project's.
- **Partial index and Prisma:** checked with Prisma 7.10.1 against a `prisma dev` database: a partial unique index created by raw SQL in a migration is ignored by the differ (`prisma migrate diff --from-migrations … --to-schema …` prints `-- This is an empty migration.`), so `prisma migrate dev` will not drop it. Prisma 7.10 also has a `partialIndexes` preview feature; this plan doesn't use it.
- **Concurrency on `prisma dev`:** it accepts a second connection, but it is PGlite behind `pglite-socket`, which runs one transaction at a time across all connections. A second insert of an `ACTIVE` hold for the same unit fails with Postgres error 23505, which `@prisma/adapter-pg` reports as Prisma `P2002` (with `meta.driverAdapterError.cause.constraint.index` = `UnitHold_unitId_active_key`). So the race check (Task 7) on the throwaway database proves that exactly one hold wins, the loser's Arabic message, and that the partial index refuses a second active hold; it does not prove a real `FOR UPDATE` wait or truly concurrent inserts, because the two transactions never overlap. Run it once more against a real PostgreSQL on localhost (e.g. a Docker `postgres` container, migrated and seeded) to prove those.
- **Excel import paths:** two code paths write unit statuses from Excel: the portal's per-project import (`importProjectUnits` in `src/lib/admin/import/workbook.ts`) and the admin's full workbook import (`importWorkbook`, units sheet). Both release holds.
- **`onDelete: Restrict` on `UnitHold.salesAccountId`:** the admin can delete a developer (`deleteDeveloper`), which cascades to its sales accounts. Postgres's `ON DELETE RESTRICT` could refuse that when a hold is still there, depending on the order the cascades run, so `deleteDeveloper` deletes the developer's holds first, in the same transaction.
- **Lock order:** every hold write locks the unit row first (status changes do it by updating the unit), then touches holds. A portal status change and a new hold can't interleave into an active hold on a sold unit, and the two never deadlock.

```ts
// src/lib/sales/holds.ts
import type { FormReader } from "@/lib/admin/form";

// Rules for temporary holds (spec section 6) as pure functions, so they are unit-tested.
// The database allows one ACTIVE hold per unit; these decide who may do what and whether a hold
// still counts. A hold is "live" while ACTIVE and its time hasn't run out. Nothing runs on a
// schedule: an expired hold just isn't live, and is marked RELEASED the next time it is touched.

export const HOLD_HOURS_MIN = 1;
export const HOLD_HOURS_MAX = 168;
export const DEFAULT_HOLD_HOURS = 48;

export type HoldStatusValue = "ACTIVE" | "CONVERTED" | "RELEASED";
export type HoldReleaseReasonValue = "EXPIRED" | "CANCELLED" | "PORTAL_STATUS_CHANGE" | "ADMIN_STATUS_CHANGE";
export type AvailabilityValue = "AVAILABLE" | "RESERVED" | "SOLD";

/** The signed-in salesperson. */
export type HoldActor = { id: string; role: "AGENT" | "LEAD"; developerId: string };

/** What the rules need to know about a hold. `developerId` is the developer of the held unit. */
export type HoldFacts = { salesAccountId: string; developerId: string; status: HoldStatusValue; expiresAt: Date };

const inRange = (n: number | null | undefined): n is number =>
  typeof n === "number" && Number.isInteger(n) && n >= HOLD_HOURS_MIN && n <= HOLD_HOURS_MAX;

/** How long a new hold lasts: the project's own setting, else the developer's, else 48 hours. */
export function effectiveHoldHours(projectHours: number | null | undefined, developerHours: number | null | undefined): number {
  if (inRange(projectHours)) return projectHours;
  if (inRange(developerHours)) return developerHours;
  return DEFAULT_HOLD_HOURS;
}

export const holdExpiry = (from: Date, hours: number) => new Date(from.getTime() + hours * 60 * 60 * 1000);

/** Still holding the unit: ACTIVE and its time not yet up. */
export const isHoldLive = (hold: Pick<HoldFacts, "status" | "expiresAt">, now = new Date()) =>
  hold.status === "ACTIVE" && hold.expiresAt.getTime() > now.getTime();

/** Only the salesperson who holds it can turn a live hold into a reservation. */
export const canConvertHold = (actor: HoldActor, hold: HoldFacts, now = new Date()) =>
  isHoldLive(hold, now) && hold.developerId === actor.developerId && hold.salesAccountId === actor.id;

/** The holder, or a team lead of the same developer, can cancel a live hold. */
export const canCancelHold = (actor: HoldActor, hold: HoldFacts, now = new Date()) =>
  isHoldLive(hold, now) && hold.developerId === actor.developerId && (hold.salesAccountId === actor.id || actor.role === "LEAD");

/** What a salesperson sees for a unit. HELD = available, with a live hold on it. */
export const SALES_STATES = ["AVAILABLE", "HELD", "RESERVED", "SOLD"] as const;
export type SalesState = (typeof SALES_STATES)[number];

/** Search order: available first, then held, reserved and sold. */
export const SALES_STATE_RANK: Record<SalesState, number> = { AVAILABLE: 0, HELD: 1, RESERVED: 2, SOLD: 3 };

export const salesState = (availability: AvailabilityValue, held: boolean): SalesState =>
  availability === "AVAILABLE" && held ? "HELD" : availability;

/** Reads an hours field (whole hours, 1 to 168). Empty reads as null, and is an error only when required. */
export function readHoldHours(f: FormReader, name: string, { required = false } = {}): number | null {
  const hours = f.int(name, { required, min: HOLD_HOURS_MIN, max: HOLD_HOURS_MAX });
  if (f.errors[name] && f.errors[name] !== "هذا الحقل مطلوب") f.errors[name] = `اكتب عدد ساعات صحيح من ${HOLD_HOURS_MIN} لـ ${HOLD_HOURS_MAX}`;
  return hours;
}
```

```ts
// src/lib/sales/budget.ts
import { paymentBreakdown } from "@/lib/catalog/payment";
import type { PaymentPlan } from "@/lib/catalog/types";

// The Sales search's budget filter. The salesperson types one amount and says what it is: the
// whole price, the down payment, or the monthly installment. Down payments and installments come
// from the same payment math as the calculator (catalog/payment.ts), so the two always agree.

export const BUDGET_BASES = ["total", "down", "monthly"] as const;
export type BudgetBasis = (typeof BUDGET_BASES)[number];
export const BUDGET_LABELS: Record<BudgetBasis, string> = { total: "السعر الكلي", down: "المقدم", monthly: "القسط الشهري" };

/** An active payment plan as Sales reads it: the catalog's terms plus its id, the unit type it is limited to, and its maintenance. */
export type SalesPlan = PaymentPlan & { id: string; typologyId: string | null; maintenancePct?: number };

/** The plans a unit of this type is sold on: the project's general plans and the type's own. */
export const plansForType = (plans: SalesPlan[], typologyId: string) => plans.filter((p) => p.typologyId === null || p.typologyId === typologyId);

export type BudgetFigure = { value: number; planId: string | null };

/**
 * The amount a budget is compared with: the price itself, or the lowest down payment / monthly
 * installment over `plans` (only `planId` when one is chosen). Null when no plan gives one.
 */
export function budgetFigure(price: number, plans: SalesPlan[], basis: BudgetBasis, planId?: string): BudgetFigure | null {
  if (basis === "total") return { value: price, planId: null };
  let best: BudgetFigure | null = null;
  for (const plan of plans) {
    if (planId && plan.id !== planId) continue;
    const b = paymentBreakdown(price, plan);
    // A cash plan has no installments, so it can't meet a monthly budget.
    if (basis === "monthly" && b.cash) continue;
    const value = basis === "down" ? b.down : b.monthly;
    if (!best || value < best.value) best = { value, planId: plan.id };
  }
  return best;
}

/** Within the budget, to the nearest pound. */
export function fitsBudget(figure: BudgetFigure | null, amount: number): figure is BudgetFigure {
  return figure !== null && Math.round(figure.value) <= amount;
}

/** A plan's name, or its terms when the developer didn't name it. */
export function planLabel(plan: Pick<SalesPlan, "name" | "downPaymentPct" | "years" | "cashDiscountPct">): string {
  const named = plan.name.ar.trim() || plan.name.en.trim();
  if (named) return named;
  if (plan.years === 0) return plan.cashDiscountPct ? `كاش (خصم ${plan.cashDiscountPct}%)` : "كاش";
  const years = plan.years === 1 ? "سنة" : `${plan.years} ${plan.years <= 10 ? "سنين" : "سنة"}`;
  return `${plan.downPaymentPct}% مقدم · ${years}`;
```

```ts
// src/lib/sales/search.ts
import { isSubType, isUnitView, type SubType, type UnitView } from "@/lib/property";
import { BUDGET_BASES, type BudgetBasis } from "./budget";
import { SALES_STATES, type SalesState } from "./holds";

// The Sales inventory search lives in the URL (/sales?project=…&beds=3&budget=…), so a salesperson
// can send a search to a colleague. Unknown or malformed values are dropped, never trusted; ids are
// checked against the salesperson's own company by the page.

export type SalesSearch = {
  project?: string;
  /** A unit type of the chosen project. */
  model?: string;
  type?: SubType;
  /** 5 means five or more. */
  beds?: number;
  floorMin?: number;
  floorMax?: number;
  view?: UnitView;
  state?: SalesState;
  budget?: number;
  by: BudgetBasis;
  /** A plan of the chosen project, for a down payment or monthly budget. */
  plan?: string;
  page: number;
};

type Params = Record<string, string | string[] | undefined>;

const one = (v: string | string[] | undefined) => (Array.isArray(v) ? v[0] : v)?.trim() || undefined;
const id = (v: string | string[] | undefined) => {
  const s = one(v);
  return s && /^[a-z0-9]{10,40}$/i.test(s) ? s : undefined;
};
/** A whole number typed with Western or Arabic-Indic digits, commas or spaces, within [min, max]. */
const int = (v: string | string[] | undefined, min: number, max: number) => {
  const s = one(v)
    ?.replace(/[\u0660-\u0669]/g, (d) => String(d.charCodeAt(0) - 0x0660))
    .replace(/[,\s\u066C]/g, "");
  if (!s || !/^-?\d+$/.test(s)) return undefined;
  const n = Number(s);
  return n >= min && n <= max ? n : undefined;
};
const isState = (v: string | undefined): v is SalesState => (SALES_STATES as readonly string[]).includes(v ?? "");
const isBasis = (v: string | undefined): v is BudgetBasis => (BUDGET_BASES as readonly string[]).includes(v ?? "");

/** URL parameters → a search. Keys that aren't set are left out (not undefined), so searches compare cleanly. */
export function readSalesSearch(params: Params): SalesSearch {
  const type = one(params.type);
  const view = one(params.view);
  const state = one(params.state);
  const by = one(params.by);
  const project = id(params.project);
  let floorMin = int(params.floorMin, -5, 200);
  let floorMax = int(params.floorMax, -5, 200);
  if (floorMin !== undefined && floorMax !== undefined && floorMin > floorMax) [floorMin, floorMax] = [floorMax, floorMin];
  const out: SalesSearch = {
    project,
    // A unit type or plan only means something inside the chosen project.
    model: project ? id(params.model) : undefined,
    type: isSubType(type) ? type : undefined,
    beds: int(params.beds, 1, 5),
    floorMin,
    floorMax,
    view: isUnitView(view) ? view : undefined,
    state: isState(state) ? state : undefined,
    budget: int(params.budget, 1, 100_000_000_000),
    by: isBasis(by) ? by : "total",
    plan: project ? id(params.plan) : undefined,
    page: int(params.page, 1, 10_000) ?? 1,
  };
  return Object.fromEntries(Object.entries(out).filter(([, v]) => v !== undefined)) as SalesSearch;
}

const KEYS = ["project", "model", "type", "beds", "floorMin", "floorMax", "view", "state", "budget", "by", "plan", "page"] as const;

/** The /sales URL for a search, with `changes` applied (an undefined value clears that filter). */
export function searchHref(search: SalesSearch, changes: Partial<SalesSearch> = {}): string {
  const next: SalesSearch = { ...search, ...changes };
  const query = new URLSearchParams();
  for (const key of KEYS) {
    const value = next[key];
    if (value === undefined || value === "") continue;
    if (key === "page" && value === 1) continue;
    if (key === "by" && (value === "total" || next.budget === undefined)) continue;
    query.set(key, String(value));
  }
  const qs = query.toString();
  return qs ? `/sales?${qs}` : "/sales";
}

/** Filters set in the filters box (the project is picked with the chips above it). */
export function activeFilterCount(s: SalesSearch): number {
  const floor = s.floorMin !== undefined || s.floorMax !== undefined;
  return [s.model, s.type, s.beds, s.view, s.state, s.budget].filter((v) => v !== undefined).length + (floor ? 1 : 0);
}
```

```ts
// src/lib/sales/hold-service.ts
import "server-only";
import { db } from "@/lib/db";
import { Prisma } from "@/generated/prisma/client";
import { formatDateTimeAr } from "@/lib/format";
import { canCancelHold, canConvertHold, effectiveHoldHours, holdExpiry, type HoldActor, type HoldFacts } from "./holds";

// Temporary holds (spec section 6). Each write is one transaction that locks the unit row first:
// a portal or admin status change also updates the unit row before it releases holds, so the two
// wait for each other instead of leaving a live hold on a sold unit, and they never deadlock.
// The partial unique index "UnitHold_unitId_active_key" is the real guarantee of one hold per unit.

type Client = typeof db;
type Tx = Prisma.TransactionClient;
export type HoldResult = { ok: boolean; message: string };
type Options = { client?: Client; now?: Date };

/** Holds that still count: ACTIVE and not yet expired. */
export function liveHoldWhere(now = new Date()): Prisma.UnitHoldWhereInput {
  return { status: "ACTIVE", expiresAt: { gt: now } };
}

/** Marks the expired ACTIVE holds among `where` as RELEASED (EXPIRED): "released the first time something touches it". */
export function releaseExpired(client: Client | Tx, where: Prisma.UnitHoldWhereInput, now = new Date()) {
  return client.unitHold.updateMany({
    where: { AND: [where, { status: "ACTIVE", expiresAt: { lte: now } }] },
    data: { status: "RELEASED", releaseReason: "EXPIRED" },
  });
}

/** Takes a row lock on the unit for the rest of the transaction. */
const lockUnit = (tx: Tx, unitId: string) => tx.$queryRaw`SELECT "id" FROM "Unit" WHERE "id" = ${unitId} FOR UPDATE`;

/** Thrown inside a transaction to roll it back and answer with `result`. */
class Rollback extends Error {
  constructor(readonly result: HoldResult) {
    super(result.message);
  }
}

/** Holds `unitId` for the salesperson, for the project's (or developer's) hold hours. */
export async function createHold(
  input: { account: HoldActor; unitId: string; clientNote: string | null },
  { client = db, now = new Date() }: Options = {},
): Promise<HoldResult> {
  const { account, unitId, clientNote } = input;
  try {
    return await client.$transaction(async (tx): Promise<HoldResult> => {
      // Lock the unit, and only if it is this developer's, in a published project, of a priced type.
      const found = await tx.$queryRaw<{ id: string }[]>`
        SELECT u."id" FROM "Unit" u
        JOIN "Typology" t ON t."id" = u."typologyId"
        JOIN "Project" p ON p."id" = t."projectId"
        WHERE u."id" = ${unitId} AND p."developerId" = ${account.developerId}
          AND p."published" = true AND t."priceFrom" IS NOT NULL
        FOR UPDATE OF u`;
      if (!found.length) return { ok: false, message: "الوحدة دي مش موجودة في مشروعات شركتك" };
      // 1. A hold whose time ran out no longer blocks the unit.
      await releaseExpired(tx, { unitId }, now);
      // 2. Only an available unit can be held.
      const unit = await tx.unit.findUniqueOrThrow({
        where: { id: unitId },
        select: { availability: true, typology: { select: { project: { select: { holdHours: true, developer: { select: { holdHours: true } } } } } } },
      });
      if (unit.availability !== "AVAILABLE") return { ok: false, message: "الوحدة دي مش متاحة دلوقتي" };
      const project = unit.typology.project;
      const expiresAt = holdExpiry(now, effectiveHoldHours(project.holdHours, project.developer.holdHours));
      // 3. Insert. A live hold by anyone makes this fail on the partial unique index (P2002).
      await tx.unitHold.create({ data: { unitId, salesAccountId: account.id, clientNote, expiresAt } });
      return { ok: true, message: `اتحجزت ليك ✓ لحد ${formatDateTimeAr(expiresAt)}` };
    });
  } catch (e) {
    if (!(e instanceof Prisma.PrismaClientKnownRequestError && e.code === "P2002")) throw e;
    // 4. Someone else's hold got there first.
    const winner = await client.unitHold.findFirst({
      where: { unitId, status: "ACTIVE" },
      select: { salesAccountId: true, salesAccount: { select: { nameAr: true } } },
    });
    if (winner?.salesAccountId === account.id) return { ok: false, message: "الوحدة دي محجوزة ليك بالفعل" };
    return { ok: false, message: `الوحدة لسه اتحجزت لـ ${winner?.salesAccount.nameAr ?? "زميل"}` };
  }
}

/** A hold of this developer's units, with what the rules need. */
async function findHold(client: Client, developerId: string, holdId: string): Promise<(HoldFacts & { id: string; unitId: string }) | null> {
  const h = await client.unitHold.findFirst({
    where: { id: holdId, unit: { typology: { project: { developerId } } } },
    select: { id: true, unitId: true, salesAccountId: true, status: true, expiresAt: true, unit: { select: { typology: { select: { project: { select: { developerId: true } } } } } } },
  });
  return h && { id: h.id, unitId: h.unitId, salesAccountId: h.salesAccountId, status: h.status, expiresAt: h.expiresAt, developerId: h.unit.typology.project.developerId };
}

const GONE: HoldResult = { ok: false, message: "الحجز ده مش موجود" };
const OVER: HoldResult = { ok: false, message: "الحجز ده خلص وقته أو اتلغى" };

/** The holder confirms: the unit becomes RESERVED and the hold CONVERTED, together. */
export async function convertHold(account: HoldActor, holdId: string, { client = db, now = new Date() }: Options = {}): Promise<HoldResult> {
  const hold = await findHold(client, account.developerId, holdId);
  if (!hold) return GONE;
  if (!canConvertHold(account, hold, now)) {
    return hold.salesAccountId !== account.id ? { ok: false, message: "صاحب الحجز بس هو اللي يقدر يأكده" } : OVER;
  }
  try {
    return await client.$transaction(async (tx): Promise<HoldResult> => {
      await lockUnit(tx, hold.unitId);
      // Re-checked under the lock: still ACTIVE, still unexpired, still this salesperson's.
      const converted = await tx.unitHold.updateMany({
        where: { id: hold.id, salesAccountId: account.id, status: "ACTIVE", expiresAt: { gt: now } },
        data: { status: "CONVERTED" },
      });
      if (!converted.count) throw new Rollback(OVER);
      const reserved = await tx.unit.updateMany({ where: { id: hold.unitId, availability: "AVAILABLE" }, data: { availability: "RESERVED" } });
      if (!reserved.count) throw new Rollback({ ok: false, message: "الوحدة مبقتش متاحة، فالحجز ماتأكدش" });
      return { ok: true, message: "الحجز اتأكد ✓ الوحدة بقت محجوزة" };
    });
  } catch (e) {
    if (e instanceof Rollback) return e.result;
    throw e;
  }
}

/** The holder or a team lead cancels: the hold is RELEASED and the unit stays AVAILABLE. */
export async function cancelHold(account: HoldActor, holdId: string, { client = db, now = new Date() }: Options = {}): Promise<HoldResult> {
  const hold = await findHold(client, account.developerId, holdId);
  if (!hold) return GONE;
  if (!canCancelHold(account, hold, now)) {
    return hold.salesAccountId !== account.id && account.role !== "LEAD" ? { ok: false, message: "صاحب الحجز أو قائد الفريق بس هو اللي يقدر يلغيه" } : OVER;
  }
  const { count } = await client.unitHold.updateMany({
    where: { id: hold.id, status: "ACTIVE", expiresAt: { gt: now } },
    data: { status: "RELEASED", releaseReason: "CANCELLED", releasedById: account.id },
  });
  return count ? { ok: true, message: "اتلغى الحجز ✓ الوحدة رجعت متاحة" } : OVER;
}

/**
 * After a portal or admin change, releases the holds on units that are no longer AVAILABLE.
 * Call it inside the transaction that changed the units, after the change (the unit rows are then
 * locked, so no new hold can slip in). Returns how many live holds were released.
 */
export async function releaseHoldsOfUnavailable(
  tx: Tx,
  units: { id: string; availability: string }[],
  reason: "PORTAL_STATUS_CHANGE" | "ADMIN_STATUS_CHANGE",
  now = new Date(),
): Promise<number> {
  const ids = units.filter((u) => u.availability !== "AVAILABLE").map((u) => u.id);
  if (!ids.length) return 0;
  await releaseExpired(tx, { unitId: { in: ids } }, now);
  const { count } = await tx.unitHold.updateMany({ where: { unitId: { in: ids }, status: "ACTIVE" }, data: { status: "RELEASED", releaseReason: reason } });
  return count;
}

/** Live holds on these units, by unit id: who holds each one and until when. */
export async function liveHoldsByUnit(unitIds: string[], now = new Date()): Promise<Record<string, { name: string; expiresAt: Date }>> {
  if (!unitIds.length) return {};
  const rows = await db.unitHold.findMany({
    where: { unitId: { in: unitIds }, ...liveHoldWhere(now) },
    select: { unitId: true, expiresAt: true, salesAccount: { select: { nameAr: true } } },
  });
  return Object.fromEntries(rows.map((r) => [r.unitId, { name: r.salesAccount.nameAr, expiresAt: r.expiresAt }]));
}
```

```ts
 * Two salespeople press «احجز» on the same unit at the same moment: exactly one may win (spec
 * section 11). Runs the real createHold on two separate database connections. It refuses any
 * database that isn't on this machine, so it can't touch the live one.
 *

import assert from "node:assert/strict";
import { PrismaPg } from "@prisma/adapter-pg";
import { Prisma, PrismaClient } from "../src/generated/prisma/client";
import { createHold } from "../src/lib/sales/hold-service";

const ROUNDS = 8;

async function main() {
  const url = process.env.DATABASE_URL;
  if (!url || !["localhost", "127.0.0.1"].includes(new URL(url).hostname)) {
    throw new Error("hold-race: DATABASE_URL must point at a throwaway database on this machine.");
  }
  // Two clients with one connection each, so the two holds really run side by side.
  const connect = () => new PrismaClient({ adapter: new PrismaPg({ connectionString: url, max: 1 }) });
  const [a, b] = [connect(), connect()];
  const candidates = await a.unit.findMany({
    where: { availability: "AVAILABLE", holds: { none: { status: "ACTIVE" } }, typology: { priceFrom: { not: null }, project: { published: true } } },
    select: { id: true, typology: { select: { project: { select: { developerId: true } } } } },
    take: 200,
  });
  assert.ok(candidates.length > 0, "no available unit in a published project: run npm run db:seed first");
  const developerId = candidates[0].typology.project.developerId;
  const units = candidates.filter((u) => u.typology.project.developerId === developerId).slice(0, ROUNDS);
  const tag = `race-${Date.now()}`;
  const make = (suffix: string) =>
    a.salesAccount.create({ data: { developerId, username: `${tag}-${suffix}`, passwordHash: "x", nameAr: `${tag}-${suffix}`, phone: "01000000000", mustChangePassword: false } });
  const [one, two] = [await make("a"), await make("b")];
  try {
    for (const unit of units) {
      const results = await Promise.all([
        createHold({ account: { id: one.id, role: "AGENT", developerId }, unitId: unit.id, clientNote: null }, { client: a }),
        createHold({ account: { id: two.id, role: "AGENT", developerId }, unitId: unit.id, clientNote: null }, { client: b }),
      ]);
      assert.equal(results.filter((r) => r.ok).length, 1, `unit ${unit.id}: ${JSON.stringify(results)}`);
      const loser = results.find((r) => !r.ok)!;
      assert.match(loser.message, new RegExp(`الوحدة لسه اتحجزت لـ ${tag}-[ab]`));
      assert.equal(await a.unitHold.count({ where: { unitId: unit.id, status: "ACTIVE" } }), 1);
    }
    // The index on its own, without the service's lock: a second ACTIVE hold row is refused.
    await assert.rejects(
      b.unitHold.create({ data: { unitId: units[0].id, salesAccountId: two.id, expiresAt: new Date(Date.now() + 3_600_000) } }),
      (e) => e instanceof Prisma.PrismaClientKnownRequestError && e.code === "P2002",
    );
    console.log(`hold-race OK: ${units.length} rounds, exactly one hold won each time; the index refuses a second active hold.`);
  } finally {
    await a.unitHold.deleteMany({ where: { salesAccountId: { in: [one.id, two.id] } } });
    await a.salesAccount.deleteMany({ where: { id: { in: [one.id, two.id] } } });
    await Promise.all([a.$disconnect(), b.$disconnect()]);
  }
}

  (e) => {
    console.error(e);
    process.exit(1);

);
```

```ts
import { db } from "@/lib/db";
import type { Prisma } from "@/generated/prisma/client";
import type { SubType } from "@/lib/property";
import { budgetFigure, fitsBudget, plansForType, type SalesPlan } from "./budget";

// What AqarArena Sales reads: one developer's published projects, their units and active plans.
// Every query is scoped by the signed-in salesperson's developer; another company's ids find nothing.

/** Results per page, and how many units one search looks at (available ones first). */
export const PAGE_SIZE = 40;
const SCAN_LIMIT = 2000;

/** Only unit types with a starting price are shown and sold (the public catalog's rule too). */
const priced = { priceFrom: { not: null } } satisfies Prisma.TypologyWhereInput;
const dec = (v: Prisma.Decimal | null) => (v === null ? null : Number(v));
const todayUtc = () => new Date(new Date().toISOString().slice(0, 10) + "T00:00:00Z");

export type SalesProject = {
  id: string;
  nameAr: string;
  types: { id: string; code: string; nameAr: string | null; subType: SubType; bedrooms: number | null }[];
  available: number;
  total: number;
};

/** The developer's published projects that have priced unit types, with available / total unit counts. */
export async function salesProjects(developerId: string): Promise<SalesProject[]> {
  const projects = await db.project.findMany({
    where: { developerId, published: true, typologies: { some: priced } },
    orderBy: { nameAr: "asc" },
    select: { id: true, nameAr: true, typologies: { where: priced, orderBy: { priceFrom: "asc" }, select: { id: true, code: true, nameAr: true, subType: true, bedrooms: true } } },
  });
  const typeIds = projects.flatMap((p) => p.typologies.map((t) => t.id));
  const counts = typeIds.length
    ? await db.unit.groupBy({ by: ["typologyId", "availability"], where: { typologyId: { in: typeIds } }, _count: { _all: true } })
    : [];
  const projectOf = new Map(projects.flatMap((p) => p.typologies.map((t) => [t.id, p.id] as const)));
  const totals = new Map<string, { available: number; total: number }>();
  for (const c of counts) {
    const projectId = projectOf.get(c.typologyId)!;
    const t = totals.get(projectId) ?? { available: 0, total: 0 };
    t.total += c._count._all;
    if (c.availability === "AVAILABLE") t.available += c._count._all;
    totals.set(projectId, t);
  }
  return projects.map((p) => ({ id: p.id, nameAr: p.nameAr, types: p.typologies, ...(totals.get(p.id) ?? { available: 0, total: 0 }) }));
}

/** Active plans that haven't passed their end date, by project. */
export async function salesPlans(projectIds: string[]): Promise<Map<string, SalesPlan[]>> {
  const rows = projectIds.length
    ? await db.paymentPlan.findMany({
        where: { projectId: { in: projectIds }, isActive: true, OR: [{ validUntil: null }, { validUntil: { gte: todayUtc() } }] },
        orderBy: { createdAt: "asc" },
      })
    : [];
  const byProject = new Map<string, SalesPlan[]>();
  for (const p of rows) {
    const plan: SalesPlan = {
      id: p.id,
      typologyId: p.typologyId,
      name: { ar: p.nameAr ?? p.nameEn ?? "", en: p.nameEn ?? p.nameAr ?? "" },
      downPaymentPct: Number(p.downPaymentPct),
      deliveryPaymentPct: Number(p.deliveryPaymentPct),
      years: p.years,
      frequency: p.frequency,
      cashDiscountPct: dec(p.cashDiscountPct) ?? undefined,
      maintenancePct: dec(p.maintenancePct) ?? undefined,
    };
    byProject.set(p.projectId, [...(byProject.get(p.projectId) ?? []), plan]);
  }
  return byProject;
}

/** The units matching a search, available first, then by price. `capped` when more units matched than one search looks at. */
export async function searchUnits(
  me: { id: string; developerId: string },
  s: SalesSearch,
  plans: Map<string, SalesPlan[]>,
  now = new Date(),
): Promise<{ rows: SalesUnitRow[]; capped: boolean }> {
  const typology: Prisma.TypologyWhereInput = {
    ...priced,
    project: { developerId: me.developerId, published: true, ...(s.project ? { id: s.project } : {}) },
    ...(s.model ? { id: s.model } : {}),
    ...(s.type ? { subType: s.type } : {}),
    ...(s.beds ? { bedrooms: s.beds >= 5 ? { gte: 5 } : s.beds } : {}),
  };
  const where: Prisma.UnitWhereInput = {
    typology,
    ...(s.floorMin !== undefined || s.floorMax !== undefined ? { floor: { gte: s.floorMin, lte: s.floorMax } } : {}),
    ...(s.view ? { view: s.view } : {}),
    ...(s.state ? { availability: s.state === "HELD" ? "AVAILABLE" : s.state } : {}),
    // A total-price budget narrows the scan in the database too; the exact check is below.
    ...(s.budget && s.by === "total" ? { OR: [{ price: { lte: s.budget + 0.5 } }, { price: null, typology: { priceFrom: { lte: s.budget + 0.5 } } }] } : {}),
  };
  const units = await db.unit.findMany({
    where,
    orderBy: [{ availability: "asc" }, { typology: { priceFrom: "asc" } }, { id: "asc" }],
    take: SCAN_LIMIT + 1,
    select: {
      id: true,
      building: true,
      unitNumber: true,
      floor: true,
      view: true,
      price: true,
      availability: true,
      typologyId: true,
      typology: { select: { code: true, nameAr: true, subType: true, bedrooms: true, priceFrom: true, project: { select: { id: true, nameAr: true } } } },
      holds: { where: liveHoldWhere(now), take: 1, select: { salesAccountId: true, expiresAt: true, salesAccount: { select: { nameAr: true } } } },
    },
  });
  const rows: SalesUnitRow[] = [];
  for (const u of units.slice(0, SCAN_LIMIT)) {
    const hold = u.holds[0];
    const state = salesState(u.availability, Boolean(hold));
    if (s.state && state !== s.state) continue;
    const price = Number(u.price ?? u.typology.priceFrom);
    let figure: number | null = null;
    if (s.budget) {
      const f = budgetFigure(price, plansForType(plans.get(u.typology.project.id) ?? [], u.typologyId), s.by, s.plan);
      if (!fitsBudget(f, s.budget)) continue;
      figure = s.by === "total" ? null : f.value;
    }
    rows.push({
      id: u.id,
      label: unitLabel(u),
      projectName: u.typology.project.nameAr,
      typeCode: u.typology.code,
      typeName: u.typology.nameAr,
      subType: u.typology.subType,
      bedrooms: u.typology.bedrooms,
      floor: u.floor,
      view: u.view,
      price,
      figure,
      state,
      hold: hold ? { name: hold.salesAccount.nameAr, expiresAt: hold.expiresAt, mine: hold.salesAccountId === me.id } : null,
    });
  }
  rows.sort(
    (a, b) =>
      SALES_STATE_RANK[a.state] - SALES_STATE_RANK[b.state] ||
      a.price - b.price ||
      a.projectName.localeCompare(b.projectName, "ar") ||
      a.label.localeCompare(b.label, "en", { numeric: true }),
  );
  return { rows, capped: units.length > SCAN_LIMIT };
}
```

```ts
"use server";

import { revalidatePath } from "next/cache";
import { FormReader, type FormState } from "@/lib/admin/form";
import { cancelHold, convertHold, createHold } from "@/lib/sales/hold-service";
import type { HoldActor } from "@/lib/sales/holds";
import { requireSales, type SalesUser } from "@/lib/sales/session";

// Each action re-reads the session (requireSales signs out a disabled account) and hands the hold
// service the salesperson's own developer, which scopes every query: another company's id is "not found".
// The page is refreshed either way, so a lost race shows who won.

const actor = (me: SalesUser): HoldActor => ({ id: me.id, role: me.role, developerId: me.developer.id });
const NOT_FOUND: FormState = { ok: false, message: "الوحدة أو الحجز ده مش موجود" };

export async function holdUnit(_: FormState, data: FormData): Promise<FormState> {
  const me = await requireSales();
  const f = new FormReader(data);
  const unitId = f.id("unitId");
  const clientNote = f.text("clientNote", { max: 200 });
  if (!f.ok) return f.result();
  if (!unitId) return NOT_FOUND;
  const result = await createHold({ account: actor(me), unitId, clientNote });
  revalidatePath("/sales", "layout");
  return result;
}

export async function convertUnitHold(_: FormState, data: FormData): Promise<FormState> {
  const me = await requireSales();
  const holdId = new FormReader(data).id("holdId");
  if (!holdId) return NOT_FOUND;
  const result = await convertHold(actor(me), holdId);
  revalidatePath("/sales", "layout");
  return result;
}

export async function cancelUnitHold(_: FormState, data: FormData): Promise<FormState> {
  const me = await requireSales();
  const holdId = new FormReader(data).id("holdId");
  if (!holdId) return NOT_FOUND;
  const result = await cancelHold(actor(me), holdId);
  revalidatePath("/sales", "layout");
  return result;
}
```

```tsx
import Link from "next/link";
import type { SalesProject } from "@/lib/sales/inventory";
import { searchHref, type SalesSearch } from "@/lib/sales/search";

const num = (n: number) => n.toLocaleString("ar-EG");
const chip =
  "press inline-flex min-h-11 shrink-0 flex-col justify-center rounded-2xl border border-line-strong bg-surface px-4 py-1.5 text-sm text-ink no-underline hover:border-ink aria-[current=page]:border-brand aria-[current=page]:bg-brand aria-[current=page]:text-white";

/** One chip per project with how many units are available; picking one filters the search. Scrolls sideways on a phone. */
export function ProjectChips({ projects, search }: { projects: SalesProject[]; search: SalesSearch }) {
  const all = projects.reduce((t, p) => ({ available: t.available + p.available, total: t.total + p.total }), { available: 0, total: 0 });
  const items: { id?: string; nameAr: string; available: number; total: number }[] = [{ nameAr: "كل المشروعات", ...all }, ...projects];
  return (
    <nav aria-label="المشروعات" className="-mx-4 overflow-x-auto px-4 pb-1">
      <ul className="m-0 flex w-max list-none gap-2 p-0">
        {items.map((p) => (
          <li key={p.id ?? "all"}>
            <Link
              href={searchHref(search, { project: p.id, model: undefined, plan: undefined, page: 1 })}
              aria-current={search.project === p.id ? "page" : undefined}
              className={chip}
            >
              <span className="font-medium">{p.nameAr}</span>
              <span className="text-xs opacity-80">
                {num(p.available)} متاحة من {num(p.total)}
              </span>
            </Link>
          </li>
        ))}
      </ul>
    </nav>
  );
}
```

```tsx
import type { Metadata } from "next";
import Link from "next/link";
import { ProjectChips } from "@/components/sales/project-chips";
import { SalesShell } from "@/components/sales/sales-shell";
import { SearchFilters } from "@/components/sales/search-filters";
import { UnitResults } from "@/components/sales/unit-results";
import { PAGE_SIZE, salesPlans, salesProjects, searchUnits } from "@/lib/sales/inventory";
import { activeFilterCount, readSalesSearch, searchHref, type SalesSearch } from "@/lib/sales/search";
import { requireSales } from "@/lib/sales/session";

export const metadata: Metadata = { title: "المخزون" };

const num = (n: number) => n.toLocaleString("ar-EG");

// The inventory search: every unit of the company's published projects, available ones first.
// The filters live in the address, so a search can be sent to a colleague as a link.
export default async function SalesInventoryPage({ searchParams }: PageProps<"/sales">) {
  const me = await requireSales();
  const params = await searchParams;
  const asked = readSalesSearch(params);
  const projects = await salesProjects(me.developer.id);
  const plans = await salesPlans(projects.map((p) => p.id));
  // Ids from another company or an old link are dropped, never trusted.
  const project = projects.find((p) => p.id === asked.project);
  const projectPlans = project ? (plans.get(project.id) ?? []) : [];
  const search: SalesSearch = {
    ...asked,
    project: project?.id,
    model: project?.types.some((t) => t.id === asked.model) ? asked.model : undefined,
    plan: projectPlans.some((p) => p.id === asked.plan) ? asked.plan : undefined,
  };
  const { rows, capped } = await searchUnits({ id: me.id, developerId: me.developer.id }, search, plans);
  const pages = Math.max(1, Math.ceil(rows.length / PAGE_SIZE));
  const page = Math.min(search.page, pages);
  const shown = rows.slice((page - 1) * PAGE_SIZE, page * PAGE_SIZE);
  const subTypes = [...new Set(projects.flatMap((p) => p.types.map((t) => t.subType)))];

  return (
    <SalesShell me={me} title="المخزون">
      {params.password && <p className="admin-panel text-brand">تم تغيير كلمة المرور ✓</p>}
      {projects.length === 0 ? (
        <p className="admin-panel text-sm text-muted">لسه مفيش مشروعات منشورة بأسعار لشركتك على AqarArena.</p>
      ) : (
        <>
          <ProjectChips projects={projects} search={search} />
          <SearchFilters search={search} project={project} subTypes={subTypes} plans={projectPlans} count={activeFilterCount(search)} />
          <section aria-labelledby="results-title" className="admin-panel flex flex-col gap-4">
            <div className="flex flex-wrap items-baseline justify-between gap-2">
              <h2 id="results-title" className="font-display text-xl">
                {num(rows.length)} وحدة
              </h2>
              {pages > 1 && (
                <span className="text-sm text-muted">
                  صفحة {num(page)} من {num(pages)}
                </span>
              )}
            </div>
            {capped && <p className="text-sm text-brass-dark">فيه وحدات أكتر من اللي اتعرضت. اختار مشروع أو نوع عشان تشوفها كلها.</p>}
            {shown.length === 0 ? (
              <p className="rounded-2xl border border-dashed border-line-strong px-5 py-6 text-sm text-muted">
                مفيش وحدات بالمواصفات دي. جرّب ميزانية أكبر أو شيل فلتر، أو <Link href="/sales">امسح الفلاتر</Link>.
              </p>
            ) : (
              <UnitResults rows={shown} basis={search.budget ? search.by : null} />
            )}
            {pages > 1 && (
              <nav aria-label="الصفحات" className="flex items-center justify-between gap-3">
                {page > 1 ? (
                  <Link href={searchHref(search, { page: page - 1 })} className="admin-btn-ghost">
                    → السابق
                  </Link>
                ) : (
                  <span />
                )}
                {page < pages ? (
                  <Link href={searchHref(search, { page: page + 1 })} className="admin-btn-ghost">
                    التالي ←
                  </Link>
                ) : (
                  <span />
                )}
              </nav>
            )}
          </section>
        </>
      )}
    </SalesShell>
  );
}
```

```js
// cdp.mjs: one headless Chrome per signed-in person, driven over the DevTools protocol.
import { spawn } from "node:child_process";
import fs from "node:fs";
import os from "node:os";
import path from "node:path";

const CHROME = "C:/Program Files/Google/Chrome/Application/chrome.exe";
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

/** `profile` keeps each person's cookies apart. Dialogs (window.confirm) are answered with `answerDialogs(yes)`. */
export async function browser({ profile, width = 1280, height = 900, scheme = "light" }) {
  const port = 9300 + Math.floor(Math.random() * 500);
  const proc = spawn(CHROME, ["--headless=new", `--remote-debugging-port=${port}`, "--no-first-run", "--disable-gpu", `--user-data-dir=${path.join(os.tmpdir(), `cdp-${profile}`)}`, "about:blank"], { stdio: "ignore" });
  let page;
  for (let i = 0; i < 50 && !page; i++) {
    try {
      page = (await (await fetch(`http://127.0.0.1:${port}/json`)).json()).find((t) => t.type === "page");
    } catch {}
    if (!page) await sleep(200);
  }
  const ws = new WebSocket(page.webSocketDebuggerUrl);
  await new Promise((r) => (ws.onopen = r));
  let id = 0;
  let answer = true;
  const pending = new Map();
  const dialogs = [];
  const send = (method, params = {}) => new Promise((r) => { const i = ++id; pending.set(i, r); ws.send(JSON.stringify({ id: i, method, params })); });
  ws.onmessage = (m) => {
    const d = JSON.parse(m.data);
    if (d.id && pending.has(d.id)) { pending.get(d.id)(d); pending.delete(d.id); }
    if (d.method === "Page.javascriptDialogOpening") { dialogs.push(d.params.message); send("Page.handleJavaScriptDialog", { accept: answer }); }
  };
  await send("Page.enable");
  await send("Emulation.setDeviceMetricsOverride", { width, height, deviceScaleFactor: 1, mobile: width < 600 });
  await send("Emulation.setEmulatedMedia", { features: [{ name: "prefers-color-scheme", value: scheme }] });
  const evaluate = async (expression) => (await send("Runtime.evaluate", { expression, returnByValue: true, awaitPromise: true })).result?.result?.value;
  return {
    dialogs,
    answerDialogs: (yes) => (answer = yes),
    go: async (url, wait = 2500) => { await send("Page.navigate", { url }); await sleep(wait); },
    eval: evaluate,
    shot: async (file) => { const r = await send("Page.captureScreenshot", { format: "png", captureBeyondViewport: true }); fs.writeFileSync(file, Buffer.from(r.result.data, "base64")); },
    close: async () => { ws.close(); proc.kill(); await sleep(300); },
  };
}
```
